# 🚀 Aapla Vyapar - Free Deployment Guide (वेबसाइट लाइव्ह कशी करावी)

Aapki website ek **Pure Static Web App + Supabase Cloud Backend** hai, isliye isko kisi bhi free cloud hosting par 100% Free me deploy kiya ja sakta hai.

---

## 🌟 Method 1: Netlify Drop (सबसे आसान — 10 सेकंड में लाइव)
1. Browser me **https://app.netlify.com/drop** kholein.
2. Apne computer ke Downloads folder me se **Idea Lab3** folder ko mouse se pakad kar website par **Drag & Drop** (छोड़) dein.
3. 10 second ke andar aapko live link mil jayega (उदा. https://aapla-vyapar.netlify.app).

---

## 🌟 Method 2: Vercel (फास्ट और सुपर सिक्योर)
1. **https://vercel.com/signup** par free account banayein.
2. **"Add New Project"** dabayein -> Idea Lab3 folder select karein.
3. **"Deploy"** par click karein -> Website live ho jayegi!

---
